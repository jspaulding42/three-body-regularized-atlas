# Three-Body Symmetry Experiment

This folder contains a research/proof harness for a constructive
regularized-atlas route to the Newtonian three-body problem.  The target is
not a finite elementary formula or a finite first-integral formula.  The
current north star is a verifier-checkable, locally finite family of
regularized analytic charts: for each finite target time, a finite certificate
should either evaluate the projected Newtonian solution or prove a
maximal-classical total-collision stop.

The transferable idea from OpenAI's unit-distance proof is still the guiding
principle: lift into a richer structured space, construct there, project back,
and verify the projected object independently.  In this project that principle
now appears in several layers:

1. Finite-target atlas-or-stop theorem: ordinary Taylor, planar Levi-Civita,
   spatial KS, and total-stop charts resolve finite target times when the
   corresponding analytic obligations are available.
2. Open-time locally finite atlas theorem: compact finite-target prefixes are
   assembled into a countable locally finite atlas-or-stop family.  The
   exact/computable point-input version is now proof-certified by the
   finite-target theorem plus the two-sided compact-exhaustion and
   local-finiteness proofs; the interval-box set-valued constructor theorem is
   still a separate missing implementation theorem.
3. Closed-form function-class audit: `regularized_locally_finite_atlas` is the
   theorem-compatible infinite representation class, separate from
   `sundman_global_series`.
4. Endpoint-compression certificates: scattering, homothetic escape,
   uniformly noncollision, and geometric event-tail certificates are useful
   optional compressions, not prerequisites for the general theorem.
5. Remaining proof obligations: proof-grade total-collision entry/stop
   semantics, arbitrary-data construction of the recursive branch/event-order
   tree, and independent verifier coverage for the full chart language.

The original symmetry-first figure-eight work remains as a validation example:
it shows how structured lifting can recover and directly verify a nontrivial
periodic solution, the equal-mass figure-eight choreography.  It no longer
defines the main theorem target.
