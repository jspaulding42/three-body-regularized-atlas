# Security Policy

## Supported versions

This is research software under active development. Security fixes are applied
to the current development branch and the latest published release; older
versions are not guaranteed to receive updates.

## Reporting a vulnerability

Please report suspected vulnerabilities privately to
jspaulding42@hotmail.com. Include the affected revision, reproduction steps,
potential impact, and any suggested mitigation. Do not include sensitive data
that is unnecessary to reproduce the issue.

Please allow a reasonable period for acknowledgement and investigation before
public disclosure. No response-time or remediation-time guarantee is offered.

This channel is for software-security problems such as unsafe parsing,
dependency risks, or unintended code execution. Mathematical errors and
certificate-soundness concerns are equally important but should normally be
reported through the repository's issue tracker unless confidential handling
is necessary.
