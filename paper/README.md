# Paper review draft

`main.tex` is a conservative manuscript for the repository's validated local
planar binary-collision passage. It deliberately makes no general-solution or
global-atlas claim.

The immutable `v0.2.0-review` manuscript is the earlier collision-passage
snapshot. It includes a verified bibliography, accountable author and
AI-contribution disclosure, BSD-3-Clause software availability, and a
canonical repository link, and it was compiled and visually checked against
the tagged code.

The current `main.tex` contains post-tag gauge-gluing additions and is an
unreleased working draft for a prospective `v0.3.0-review` release. It has
been compiled with Tectonic and all ten rendered pages have been visually
checked locally, but it is not attached to an immutable release and no v0.3
tag or archival DOI is claimed. Independent expert mathematical assessment
also remains pending.

Suggested local build:

```bash
tectonic main.tex
```
